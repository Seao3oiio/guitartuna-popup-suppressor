# Changelog

All notable changes to this project are documented in this file.

## 1.1.0 - 2026-07-20

- Pre-arm the popup session marker before Unity initializes PlayerPrefs.
- Keep the direct marker-read hook as a fallback.
- Restrict execution to GuitarTuna's main process.
- Add defensive error handling around all preference operations.

## 1.0.0 - 2026-07-20

- Add the initial session-marker read hook for GuitarTuna 7.96.1.
